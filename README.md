# 📚 Projetos de JavaScript — Curso em Vídeo


## 📌 Sobre o projeto

Este repositório reúne exercícios e projetos desenvolvidos durante os estudos de JavaScript com o Curso em Vídeo, com o objetivo de praticar os conceitos aprendidos e desenvolver habilidades de programação.

---

## 💻 Tecnologias utilizadas

JavaScript — lógica e funcionalidades dos exercícios.
HTML5 — estrutura das páginas web.
Visual Studio Code — ambiente de desenvolvimento.

---

## 🚀 Como executar os projetos

- Clone ou baixe este repositório.
- Abra a pasta do projeto no Visual Studio Code ou em outro editor de código.
- Para os exercícios com arquivos .html, abra o arquivo no navegador.
- Para executar arquivos .js diretamente, utilize o Node.js:

   node nome_do_arquivo.js


Observação: alguns exercícios dependem de uma página HTML para funcionar corretamente. Nesses casos, abra o arquivo .html correspondente no navegador.

---

## 📂 Organização

Os arquivos estão organizados por aulas e exercícios, facilitando a consulta e a prática dos conteúdos estudados.
